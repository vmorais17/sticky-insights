# Demo GIFs

This directory holds the five demo GIFs embedded in the top-level [README](../../README.md). All are cuts from a single recorded user session:

- `pipeline-progress.gif` — click *Find Themes*, show stage messages
- `related-themes.gif` — toggle hull overlay on the canvas
- `insights-selection.gif` — Insights tab, click tile, panel opens
- `insights-consensus.gif` — zoomed contributor breakdown inside the panel
- `semantic-view.gif` — Semantics tab, hover clusters

They are regenerated by running:

```bash
# terminal 1
npm run dev

# terminal 2
npm run capture-gifs
```

See [scripts/capture-gifs.mjs](../../scripts/capture-gifs.mjs) for scene definitions.
Capture is driven by a reusable Playwright agent under `~/.claude/agents/browser-capture.md`.
